# Frontend Mentor - Social Links Profile

This is my solution to the Social Links Profile challenge on Frontend Mentor.

## 📌 Overview

The goal of this challenge was to build a responsive social profile card that matches the provided design as closely as possible.

## 🚀 What I Learned

- How to create responsive layouts without media queries
- How to use `width` and `max-width` together
- How Flexbox helps with alignment and centering
- How to avoid overflow issues by removing fixed heights
- How hover states improve user interaction

## 🛠 Built With

- Semantic HTML5
- CSS Flexbox
- Responsive design techniques
- Mobile-first workflow

## 💡 Continued Development

I would like to improve my sizing strategy and spacing consistency in future projects. I also want to become more confident in writing cleaner and more scalable CSS.
